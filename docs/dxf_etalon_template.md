# Шаблон еталона для сліпої перевірки DXF

Один файл `<назва>.etalon.md` на аркуш, поруч із `<назва>.dxf` у теці `dxf_blind/`.
Еталон пишеться **до прогону**, вручну, з креслення. Порівняння автоматичне:
`python tools/dxf_blind_check.py dxf_blind --check-etalon` перевіряє лише формат (DXF не відкривається).

## Правила

- Кожна деталь — розділ `## Деталь N — <назва>`. Кілька деталей на аркуші: зверху вниз, як на кресленні.
- Ділянки зовнішнього профілю — зліва направо, як на кресленні. Оброблені ділянки нумеруються 1, 2, … без пропусків.
- Межі: 0 = лівий кінець ділянки 1, k = правий кінець ділянки k (тобто межа між ділянками k і k+1).
- Типи ділянок: `od_turn`, `groove`, `taper`, `arc`, `thread`, `stock`.
  - `stock` — необроблена ділянка (пруток у патроні): № 0, якщо зліва (або наступний номер, якщо справа), без довжини. У межі не входить.
  - Конус: `Ø30→Ø22`. Дуга: `R10`. Різьба: як написано, `M22×1,5-6g`.
- Довжина — фактична довжина ділянки за кресленням (можна обчислену з ланцюга розмірів).
- Тексти розмірів — **як написано на кресленні**. Кома чи крапка, «−» чи «-», «×» чи «x», кирилична чи латинська «М» — не важливо.
  Однакові тексти (два «3») — кожен окремим рядком.
- У таблицю «Розміри» вносяться **всі** розміри деталі на кресленні: зовнішні, внутрішні й «поза критерієм».

## До чого прив'язаний розмір (колонка 2 таблиці «Розміри»)

| Запис | Значення |
|---|---|
| `межі 0–6` | довжина між межами 0 і 6 |
| `ділянка 3` | Ø, M, R дуги — ділянка 3 |
| `ділянка 1, 3 або 5 — будь-яка` | однаковий Ø на кількох ділянках, проставлений один раз |
| `фаска на межі 6` | фаска на межі 6 |
| `R на межі 4` | радіус переходу на межі 4 |
| `всередині ділянки 7 до межі 7` | довжина, що закінчується всередині ділянки (наприклад, глибина) |
| `внутрішній` | внутрішній профіль: отвори, розточки, внутрішня різьба — поза критерієм |
| `поза критерієм` | зовнішній елемент, який код поки не вміє: шестигранник, лиски, шпонковий паз, кутові розміри, вид з торця |

Розмір, де на кресленні геометрія не відповідає тексту, можна позначити словами `на кресленні не збігається`
у колонці 2 (наприклад, `ділянка 2, на кресленні не збігається`) — звіт покаже, чи код це помітив.
На відсоток це не впливає.

## Приклад

```
# Вал 45

## Деталь 1 — вал

### Зовнішні ділянки (зліва направо, як на кресленні)
| № | тип | Ø або R | довжина | фаска зліва | фаска справа | R переходу справа | примітка |
|---|-----|---------|---------|-------------|--------------|-------------------|----------|
| 1 | od_turn | Ø30 | 10 | 1×45° | | | |
| 2 | taper | Ø30→Ø22 | 5 | | | | |
| 3 | groove | Ø20 | 2 | | | | |
| 4 | thread | M22×1,5-6g | 21 | | 1×45° | | |
| 5 | arc | R10 | 10 | | | | сфера на торці |

Межі: 0 = лівий торець, 5 = правий торець. Сума 48.

### Внутрішні ділянки (поза критерієм)
| № | тип | Ø | довжина | примітка |
|---|-----|---|---------|----------|
| в1 | bore | Ø10H11 | 15 | з лівого торця |

### Поза критерієм (зовнішнє, чого код не вміє)
| що | розмір |
|----|--------|
| лиски | S27 |

### Розміри
| текст | до чого прив'язаний |
|-------|---------------------|
| 48 | межі 0–5 |
| 10 | межі 0–1 |
| 2 | межі 2–3 |
| Ø30 | ділянка 1 |
| Ø20 | ділянка 3 |
| M22×1,5-6g | ділянка 4 |
| R10 | ділянка 5 |
| 1×45° | фаска на межі 0 |
| 1×45° | фаска на межі 4 |
| Ø10H11 | внутрішній |
| 15 | внутрішній |
| S27 | поза критерієм |
```
