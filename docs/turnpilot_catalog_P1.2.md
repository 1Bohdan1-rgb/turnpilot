## 6. Центрувальне: НЕ ЗНАЙДЕНО

Центрувальних свердел (DIN 333) у жодному з двох каталогів немає. Найближче, що є: головка CoroMill 316 для фасок, яку можна використати для засвердлювання (SRT A166). Але це фрезерний інструмент під хвостовик EH, і режимів засвердлювання для токарного верстата каталог не дає.
Варіанти: взяти дані з каталогу виробника центрувальних (наприклад, Guhring чи Dormer), або не засвердлювати перед 860-GM (вершина 140°, самоцентрування). Друге рішення лишається за оператором.
